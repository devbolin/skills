# Readability Improver

Rewrites complex text to be clearer and more understandable.

## Principles

1. **Short sentences** - Break long sentences into shorter ones
2. **Active voice** - Use active voice instead of passive
3. **Concrete language** - Replace jargon with plain words
4. **Logical flow** - Ensure logical progression of ideas

## Before/After Examples

### Before (Complex)
```
The utilization of aforementioned methodology necessitates the implementation of comprehensive validation procedures to ensure the attainment of desired outcomes.

### After (Clear)
Use the method above. Validate thoroughly to get the expected results.
```

### Before (Jargon)
```
Leverage synergies to optimize value delivery.

### After (Plain)
Work together effectively to deliver better results.
```

## Usage

Provide text that needs improvement. Skill will:
1. Identify complex sentences
2. Simplify wording
3. Restructure for clarity
4. Preserve original meaning
