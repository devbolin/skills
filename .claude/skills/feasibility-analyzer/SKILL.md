# Feasibility Analyzer

Analyzes whether a proposal can be implemented technically.

## Analysis Dimensions

### 1. Technical Feasibility
- Current technology readiness
- Required technical capabilities
- Integration requirements

### 2. Resource Feasibility
- Available team expertise
- Infrastructure requirements
- Time constraints

### 3. Risk Factors
- Technical unknowns
- External dependencies
- Potential blockers

## Output Format

```markdown
## Feasibility Analysis

### Overall Feasibility: [Feasible/Probably Feasible/Uncertain/Probably Not Feasible]

### Technical Readiness
| Factor | Status | Notes |
|--------|--------|-------|
| ... | ... | ... |

### Key Challenges
1. ...

### Required Capabilities
- [ ] ...
- [ ] ...

### Recommendations
1. ...
```

## Questions to Consider

1. What are the technical unknowns?
2. Are there off-the-shelf solutions?
3. What's the worst-case scenario?
4. What's the minimum viable approach?
