# Get started with GitHub Copilot in VS Code

A hands-on tutorial building a task management web application while discovering VS Code's AI capabilities.

## Prerequisites

- VS Code installed
- GitHub Copilot access (Free plan available)

## Step 1: Experience inline suggestions

Create an HTML file and start typing. Copilot provides ghost text suggestions as you type. Press **Tab** to accept.

## Step 2: Build complete features with agents

1. Open Chat view (⌃⌘I)
2. Select **Agent** in the agent dropdown
3. Enter a prompt like: "Create a complete task manager web application with the ability to add, delete, and mark tasks as completed..."

The agent generates files, coordinates changes across them, and implements the feature end-to-end.

## Step 3: Make precise adjustments with inline chat

Select code in the editor, press ⌘I, and enter a targeted prompt like: "Add input validation to prevent adding empty tasks."

## Step 4: Personalize your AI experience

- Create custom instructions for coding standards
- Create custom agents (e.g., "Code Reviewer")

## Step 5: Use smart actions

AI-powered actions integrated into VS Code's interface, like generating commit messages.
