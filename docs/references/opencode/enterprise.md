# Enterprise

Using OpenCode securely in your organization.

OpenCode Enterprise ensures code and data never leaves your infrastructure via centralized config with SSO and internal AI gateway.

## Data handling
OpenCode does not store your code or context data. All processing happens locally or through direct API calls.

## Code ownership
You own all code produced by OpenCode.

## Pricing
Per-seat model. No charge for tokens used if you have your own LLM gateway.

## Deployment
- Central config via well-known endpoint
- SSO integration with your identity provider
- Internal AI gateway (disable all other providers)
- Self-hosting share pages (on roadmap)

## FAQ
Supports private npm registries via Bun's native .npmrc support.
