# Zen

Curated list of models provided by OpenCode.

Currently in beta. Works like any other provider.

## How it works
1. Sign in to OpenCode Zen, add billing, copy API key
2. Run `/connect`, select OpenCode Zen, paste key
3. Run `/models` to see available models

## Models
GPT 5.0-5.5 series, Claude Opus 4.1-4.7, Claude Sonnet 4-4.6, Claude Haiku 3.5-4.5, Gemini 3.1 Pro, Gemini 3 Flash, Qwen3.5 Plus, Qwen3.6 Plus, MiniMax M2.5/M2.7, GLM 5/5.1, Kimi K2.5/K2.6, Big Pickle (free), DeepSeek V4 Flash Free, MiniMax M2.5 Free, Ring 2.6 1T Free, Nemotron 3 Super Free

## Pricing
Pay-as-you-go per 1M tokens. Free models available. Credit card fees passed at cost (4.4% + $0.30).

## For Teams
Workspaces, roles (Admin/Member), model access control, BYOK (use your own OpenAI/Anthropic keys), monthly spending limits.
