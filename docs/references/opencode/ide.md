# IDE

The OpenCode extension for VS Code, Cursor, and other IDEs.

## Usage
- Quick Launch: Cmd+Esc (Mac) or Ctrl+Esc (Windows/Linux)
- New Session: Cmd+Shift+Esc (Mac) or Ctrl+Shift+Esc (Windows/Linux)
- File Reference Shortcuts: Cmd+Option+K (Mac) or Alt+Ctrl+K (Linux/Windows)

## Installation
Extension installs automatically when you run `opencode` in the integrated terminal.

Manual: Search for "OpenCode" in Extension Marketplace.

## Troubleshooting
Ensure CLI for your IDE is installed (code, cursor, windsurf, codium).
