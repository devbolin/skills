# TUI

Using the OpenCode terminal user interface.

Run `opencode` or `opencode /path/to/project` to start.

## File references
Use `@` for fuzzy file search. Start message with `!` for shell commands.

## Commands
/connect, /compact, /details, /editor, /exit, /export, /help, /init, /models, /new, /redo, /sessions, /share, /themes, /thinking, /undo, /unshare

## Editor setup
Set `EDITOR` env var (e.g., `export EDITOR="code --wait"`).

## Configure
Customize via `tui.json`: theme, keybinds, scroll_speed, diff_style, mouse.

## Customization
Command palette (ctrl+p) for UI settings like username display.
