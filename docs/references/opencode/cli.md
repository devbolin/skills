# CLI

OpenCode CLI options and commands.

## Default
`opencode` starts the TUI.

## Commands
agent (create/list), attach, auth (login/list/logout), github (install/run), mcp (add/list/auth/logout/debug), models, run, serve, session (list/delete), stats, export, import, web, acp, plugin, pr, db, debug, uninstall, upgrade

## Global Flags
--help, --version, --print-logs, --log-level, --pure

## Environment variables
OPENCODE_CONFIG, OPENCODE_TUI_CONFIG, OPENCODE_CONFIG_DIR, OPENCODE_CONFIG_CONTENT, OPENCODE_SERVER_PASSWORD, OPENCODE_SERVER_USERNAME, and many more for disabling features, enabling experimental capabilities, etc.
